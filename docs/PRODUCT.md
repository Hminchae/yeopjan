# 옆잔 제품 정의

## 제품 한 문장

옆잔은 혼자 술을 마시는 밤에 가입 없이 작은 가상 바에 들어가, 실제 접속자와 공간을 공유하고 원할 때만 대화하거나 건배할 수 있는 익명 모바일 웹 서비스다.

## 핵심 경험

- 첫 화면에서 실제 접속 인원과 바의 분위기를 확인한다.
- 성인 대상 안내를 확인하고 닉네임, 아바타, 선택적 기분을 정한다.
- 터치한 좌석이나 바닥으로 아바타가 이동한다.
- 바 카운터 또는 작은 테이블에 앉으면 그 공간의 대화만 보인다.
- 창가에서는 일반 대화 알림 없이 조용히 머문다.
- 음료를 꾸미고 같은 공간의 사람에게 건배와 가벼운 반응을 보낸다.
- 원치 않는 사용자를 음소거하거나 차단하고 신고할 수 있다.

## 사용자와 범위

대상은 가벼운 동행감을 원하는 성인이다. 가입, 실명, 전화번호, 위치 권한은 요구하지 않는다. 실제 주류 판매, 음주량 측정, 경쟁, 결제, 친구, DM, 음성·영상, LLM 대화는 포함하지 않는다.

## 공간

### 바 카운터

6석의 공개 대화 공간이다. 참석자만 채팅과 건배 이벤트를 받는다.

### 창가

2석의 조용한 공간이다. 아바타의 조용한 상태는 보이지만 채팅 채널은 제공하지 않는다.

### 작은 테이블

각 4석인 테이블 2개를 둔다. 테이블별로 채팅을 분리하고 만석이면 서버가 착석을 거절한다.

## MVP 운영 규칙

- 바 인스턴스는 하나이고 정원은 24명이다.
- 실제 사용자가 없으면 접속자는 0명이다. 봇 사용자나 가짜 메시지를 만들지 않는다.
- 바텐더 질문은 시스템 메시지로 명시하며, 대화가 없는 채널에 정해진 문구 중 하나만 낮은 빈도로 제시한다.
- 채팅은 300자, 닉네임은 2-16자로 제한한다.
- 음소거는 표시만 숨기고, 차단은 해당 사용자의 채팅·반응·말풍선을 숨긴다.
- 신고는 신고자 세션의 해시, 대상 내부 ID, 사유, 메시지 스냅샷만 30일 보관한다.
- 연령 확인 화면은 자기 확인 절차일 뿐 법적 연령 인증이라고 표현하지 않는다.

## 성공 기준

성공은 정적 화면 완성이 아니라 두 개의 독립 브라우저에서 입장, 존재 확인, 이동, 좌석 경합, 채널 분리 채팅, 건배, 연결 해제 정리가 네트워크를 통해 재현되는 것이다. 상세 검증은 [IMPLEMENTATION_PLAN.md](./IMPLEMENTATION_PLAN.md)의 AC 매핑을 따른다.

## 공개 전 필수 검토

- 대한민국 기준 성인 대상 서비스의 연령 확인 방식과 청소년 보호 의무
- 개인정보 처리방침, 쿠키·세션 고지, 신고 자료의 법적 보관 근거
- 익명 커뮤니티 운영 정책, 신고 대응 시간, 제재 이의 제기 절차
- 음주를 조장하지 않는 문구와 위기·중독 지원 정보의 배치
- 운영자 접근 통제, 감사 로그, 비밀 관리, HTTPS, 백업과 삭제 절차
