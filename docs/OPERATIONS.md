# 공개 전 운영 체크리스트

## 법적·정책

- 관할 지역의 성인 대상 서비스와 청소년 보호 의무 검토
- 자기 확인 화면과 법적 연령 인증의 차이를 이용약관에 명시
- 개인정보 처리방침에 익명 세션, 신고 자료, 로그의 항목·목적·기간 기록
- 커뮤니티 가이드라인, 신고 대응 시간, 제재와 이의 제기 절차 확정
- 음주 조장·경쟁 문구 금지와 중독·위기 지원 정보 검토

## 보안·개인정보

- 실제 HTTPS/WSS와 HSTS 설정
- 실제 domain만 포함하는 `ALLOWED_ORIGINS`
- 비밀 저장소의 `ADMIN_TOKEN`, 정기 교체, 퇴사자 권한 회수
- 운영자 API 접근 로그와 최소 권한
- 신고 30일 삭제 작업과 삭제 결과 점검
- 로그에 토큰·IP·메시지 본문이 없는지 표본 감사

## 신뢰성

- 목표 기기와 네트워크에서 동시 연결 부하 시험
- reverse proxy의 WebSocket upgrade와 idle timeout 확인
- SQLite volume 백업·복원 훈련
- 장애 공지와 운영 연락 경로
- 다중 서버 전환 시 공유 상태 저장소와 Redis Adapter 도입

## 콘텐츠 운영

- 신고 사유별 처리 기준과 긴급 위험 에스컬레이션
- 반복 재가입과 우회 행위 대응 기준
- 바텐더 시스템 문구 검수와 실제 사용자 오인 방지
- 접근성 제보와 모바일 브라우저 지원 범위 공개
